# Kehotesuunnittelija – Koulutus

MCP-yhteys: https://kehotesuunnittelija.fi/mcp

Yhdistä henkilökohtaisella Kehotesuunnittelija-tunnuksellasi ja valitse Premium-tilisi tai yrityksesi. Tämä paketti sisältää vain hakuohjeen. Käyttöoikeus ja sisältö tarkistetaan palvelussa jokaisella haulla. Tilauksen päättyminen estää uudet haut; aiemmin keskusteluun palautettua sisältöä ei voida poistaa.

Automaattiset plugin-päivitykset: lisää GitHub-marketplace ja ota sovelluksen synkronointi käyttöön. Kehotesuunnittelijan GitHub-asennuspaketti päivittää repositoriota säännöllisesti. Claude-organisaation GitHub-synkronointi tarvitsee yksityisen repositorion. ZIP-tuonti on manuaalinen vaihtoehto. ChatGPT Work: suora MCP-määritys tuodussa pluginissa edellyttää työpöytäsovelluksen tukea. Selainkäyttö tarvitsee erikseen rekisteröidyn sovellusyhteyden. Saatavuus riippuu oman työtilasi asetuksista.
