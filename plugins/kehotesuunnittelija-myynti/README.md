# Kehotesuunnittelija – Myynti

MCP-yhteys: https://kehotesuunnittelija.fi/mcp

Yhdistä henkilökohtaisella Kehotesuunnittelija-tunnuksellasi ja valitse Premium-tilisi tai yrityksesi. Tämä paketti sisältää vain hakuohjeen. Käyttöoikeus ja sisältö tarkistetaan palvelussa jokaisella haulla. Tilauksen päättyminen estää uudet haut; aiemmin keskusteluun palautettua sisältöä ei voida poistaa.

Plugin-päivitykset: lisää GitHub-marketplace ja päivitä lähde sovelluksen marketplace-hallinnassa. ChatGPT:n työtilatuonti tarkistaa lähteen oletuksena päivittäin. Kehotesuunnittelijan GitHub-asennuspaketti päivittää repositoriota säännöllisesti. Claude-organisaation GitHub-synkronointi tarvitsee yksityisen repositorion. Hae suoran Git-päivityksen jälkeen muutokset Clauden Update-painikkeella. Clauden automaattinen sync vaatii oletushaaraan yhdistetyn pull requestin, jossa pluginin versionumero muuttuu. ZIP-tuonti on manuaalinen vaihtoehto. ChatGPT Work: suora MCP-määritys tuodussa pluginissa edellyttää työpöytäsovelluksen tukea. Selainkäyttö tarvitsee erikseen rekisteröidyn sovellusyhteyden. Saatavuus riippuu oman työtilasi asetuksista.
